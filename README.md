# پنل پیگیری درسی — گروه مشاوره دکتر خاکسار

وب‌اپ پیگیری روزانه شاگردان با پنج نقش: مدیر، مشاور، پشتیبان، شاگرد و ولی.

## نسخه فعلی: نمایشی (GitHub Pages)
- بدون سرور اجرا می‌شود و داده‌ها فقط در مرورگر همان کاربر (localStorage) ذخیره می‌شوند.
- حساب‌های نمونه با رمز `1234`: `admin` (مدیر)، `zilabi` و `ahmadi` (مشاور)، `rezaei` (پشتیبان)، `s1003` (شاگرد)، `p1003` (ولی).
- دکمه «بازنشانی داده‌های نمونه» بالای صفحه همه‌چیز را به حالت اول برمی‌گرداند.

## ساختار
| فایل | کار |
| --- | --- |
| `index.html` | صفحه اصلی؛ با هر انتشار عدد `?v=` را بالا ببرید |
| `js/util.js` | تاریخ شمسی، روز مطالعاتی (ساعت ایران، تا ۴ صبح)، اعداد فارسی، خواندن CSV/اکسل |
| `js/store.js` | **لایه داده** — همه خواندن/نوشتن‌ها و کنترل دسترسی‌ها |
| `js/app.js` | صفحه‌های هر نقش، افزودن گروهی و عملیات گروهی |
| `css/style.css` | ظاهر (راست‌به‌چپ، موبایل و دسکتاپ، چاپ کارت ورود) |

## انتقال به سرور (لیارا)
همه صفحه‌ها فقط با توابع `Store` کار می‌کنند و همه این توابع `async` هستند.
برای نسخه واقعی، یک API روی لیارا با همین توابع ساخته می‌شود (ورود، شاگردان، گزارش‌ها، بازخورد، پیام اولیا)
و بدنه توابع `store.js` به `fetch` به آن API تبدیل می‌شود؛ صفحه‌ها تغییری نمی‌کنند.
در نسخه سرور، رمزها هش می‌شوند و کنترل دسترسی‌ها در سرور تکرار می‌شود.

## اجرای محلی
```
py -3 -m http.server 8765 --directory WebPanel
```
سپس `http://localhost:8765` را باز کنید.
